# Pomodoro CLI Timer

> **비동기(Asyncio) 방식으로 작동하는 가볍고 강력한 터미널 전용 뽀모도로 타이머입니다.**  
> 맥 OS(Mac OS) 환경에서 작동하며, 집중 시간과 휴식 시간이 끝날 때마다 시스템 사운드를 보내줍니다.

---

## 주요 기능

* **시계 렌더링:** `end='\r'`과 `flush=True`를 조합하여 줄바꿈 없이 제자리에서 시간이 줄어드는 실시간 시계 UI를 구현했습니다.
* **argparse:** CLI 환경에서 사용자로부터 유연하게 실행 매개변수를 입력받기 위해 사용되었습니다.
* **asyncio:** 타이머 대기(await asyncio.sleep(1)) 및 시스템 알림 프로세스를 제어하는 핵심 엔진입니다.

---

##  시작하기

### 1. 실행 방법
터미널에서 파이썬 파일을 실행할 때 반복 횟수(`-on`)와 타이머 스케줄(`-time`)을 옵션 인자로 넘겨줍니다.

```bash
# 25분 집중 / 5분 휴식을 3회 반복할 때
python3 pomodoro.py -on 3 -time 25/5

# 50분 집중 / 15분 휴식을 2회 반복할 때
python3 pomodoro.py -on 2 -time 50/15 
```

## 회고

- argparse 라는 새로운 모듋부터 비동기 프로그래밍까지 완전히 새로운 기능을 다뤄볼 수 있는 기회였습니다. 특히 이번에 공부할때는 평소처럼 검색 위주로 기능을 찾는 방법이 아닌 간단하게라도 문서를 흝어보는 방법으로 과제에 임하였습니다. 처음 적용할때는 어려움이 있었고 제대로 이해도 안되는 기분이었지만 점차 하다보니 어떤 느낌인지 어떻게 쓰는것인지 점점 감이 잡히는 기분이었습니다.
- 현재 설계했던 기능 중 타이머 가동 중 정지 기능, 총 집중 시간 기능, notification 기능이 빠졍있습니다. 현 세가지의 기능들 특징이 비동기프로그래밍인 asyncio 가 돌아가는 동안 작동해야 한다는 점입니다. 서브프로세스를 만들어내서 가동시킼는 방법까지 적용해보았으나 끝내 작동하지 않았습니다. 추측상 결국 비동기에대한 이해가 더 우선시 되어야 하는것 같아 추후 업데이트를 반복하며 기능을 추가하고 싶습니다
